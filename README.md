# Retail Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes retail sales data using **MySQL** to explore sales performance, customer purchasing behavior, product categories, and sales trends.

The objective is to extract meaningful business insights from transactional data using SQL queries and answer key business questions that can support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall retail sales performance.
- Identify revenue generated by each product category.
- Explore customer demographics and purchasing behavior.
- Identify high-value customers based on total sales.
- Analyze monthly sales patterns and transaction values.
- Examine sales activity across different times of the day.
- Perform basic data-quality checks before analysis.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **Query Language:** SQL
- **IDE:** MySQL Workbench
- **Version Control:** Git and GitHub

## 📂 Dataset Description

The project uses a retail sales transaction dataset containing information about transactions, customers, product categories, quantities, prices, and sales amounts.

### Table: `retail_sales`

| Column | Description |
|---|---|
| `transaction_id` | Unique identifier for each transaction |
| `sale_date` | Date of the transaction |
| `sale_time` | Time of the transaction |
| `customer_id` | Customer identifier |
| `gender` | Customer gender |
| `age` | Customer age |
| `category` | Product category |
| `quantity` | Quantity sold |
| `price_per_unit` | Price per unit |
| `cogs` | Cost of goods sold |
| `total_sale` | Total sales amount for the transaction |

## 📊 Business Questions & SQL Analysis

### 1. Sales on a Specific Date
Retrieved transactions recorded on November 5, 2022.

### 2. Clothing Transactions in November 2022
Intended to identify Clothing transactions with quantities greater than four during November 2022. The current query filters the date and quantity but still needs the condition `category = 'Clothing'` and the strict comparison `quantity > 4`.

### 3. Revenue by Product Category
Calculated total revenue and transaction count for each product category to compare category-level sales performance.

### 4. Average Customer Age in the Beauty Category
Calculated the average age of customers associated with transactions in the Beauty category.

### 5. High-Value Transactions
Retrieved transactions with a total sales amount greater than 1,000.

### 6. Transactions by Gender and Category
Compared transaction counts across gender and product category combinations.

### 7. Monthly Average Transaction Value
Calculated average transaction value for each month and identified the month or months with the highest average in each year.

*This analysis measures average transaction value, not total monthly revenue.*

### 8. Top Five Customers by Sales
Ranked customers by total sales contribution to identify the highest-value customers.

### 9. Unique Customers by Category
Counted distinct identified customers purchasing from each product category.

### 10. Sales by Time-of-Day Shift
Grouped transactions into Morning, Afternoon, and Evening shifts based on transaction time.

## 🚀 How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Clone or download this repository.
3. Open the SQL script in MySQL Workbench.
4. Review the setup statements and confirm the target database and table.
5. Import the dataset into `retail_sales` using the MySQL Table Data Import Wizard, ensuring the columns map correctly.
6. Execute the data-quality checks and review the results.
7. Run the analysis queries individually or in logical sections.
8. Review the result sets to identify patterns and findings.

**Important:** The table-creation script includes `DROP TABLE IF EXISTS retail_sales`. Running it will delete the existing table and its data before recreating it. Back up your data before rerunning the setup script.
